# Agent Behavior

이 문서는 이 repository에서 작업하는 코딩 agent를 위한 공유 행동 계약을 정의합니다.

## 작업 전

- 관련 agent adapter가 정의한 순서로 permanent context를 로드한다.
- 현재 요청, 현재 상태, 관련 파일을 조사한다.
- 기존 문서와 구현에서 증거를 찾고, 영향받는 범위를 판단한다.
- 변경 작업이라면, 구현 전에 비례적인 계획과 검증 전략을 준비한다.

## 작업 중

- 사용자 요청과 accepted decision 범위 안에서 작업한다.
- 기존 변경사항을 사용자 소유로 취급하고, 관련 없는 작업을 덮어쓰지 않는다.
- 중요한 가정과 아키텍처 변경사항을 드러낸다.
- 새 규칙은 올바른 source of truth에 한 번만 기록한다.

## 완료 전

- 관련 검증을 수행하거나, 왜 수행할 수 없었는지 명시한다.
- 최종 변경사항을 요구사항, 아키텍처, 문서 책임과 대조하여 리뷰한다.
- 완료된 작업, 남은 리스크, open decision을 구분한다.
- 다음 세션이 상태 변화를 알아야 한다면 `docs/status/current-state.md`를 갱신한다.

완료를 주장하는 것과 검증을 보여주는 것은 다릅니다. 검증 증거 없이 성공을 주장하지 마세요.
